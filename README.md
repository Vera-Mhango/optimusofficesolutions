# Optimus Office Solutions — Website Remodel

This repository contains the **remodelled version** of the Optimus Office Solutions website. The goal is to modernize the current site ([https://optimus.co.mw/](https://optimus.co.mw/)) with a cleaner UI, improved responsiveness, and updated service information.

**Live Preview:** [https://optimusofficesolutions.onrender.com/])[(https://optimusofficesolutions-t3iz.onrender.com))

---

## 🔧 Tech Stack

* Node.js & Express
* EJS templating
* HTML / CSS / JavaScript

---

## 🚀 Running the Project

```bash
git clone https://github.com/Vera-Mhango/optimusofficesolutions.git
npm install
npm start
# Visit http://localhost:3000
```

---

## 🎯 Project Purpose

As part of my internship at **Optimus Office Solutions**, I’m redesigning the website to:

* Improve UX/UI
* Make the layout mobile-friendly
* Refresh content and structure
* Maintain company branding
